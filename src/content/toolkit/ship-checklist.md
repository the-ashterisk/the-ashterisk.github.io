# Before You Ship an AI-Built Site

> Checklist by @the.ashterisk · the-ashterisk.github.io/toolkit/ship-checklist

Ten minutes, eight checks. Do them on the built version of the site, not the dev server.

1. **Read the browser tab.** Is it your name or your product, or "Vite + React"? Add a description too, so links shared in chats show something useful.
2. **Find every year.** Search the code for `2023`, `2024` and `2025`. A typed year goes stale. Let the code fill in the current one.
3. **Click every link.** Watch for `#`, `example.com`, `yourusername` and links to profiles that aren't yours.
4. **Submit every form, then find the message.** If you can't find where it went, it went nowhere.
5. **Search for leftovers.** `lorem`, `TODO`, `placeholder`, `John Doe`.
6. **Check the grey text.** Paste its colour and the background into a contrast checker. Normal text needs at least 4.5:1.
7. **Use it with only the keyboard.** Press Tab through the whole page. Can you reach and see every button?
8. **Open it on your real phone.** Look for sideways scrolling, cut-off text and buttons too small to tap.

AI writes code that looks finished. These checks are for the parts that only look finished.
